AUTOPLAYER CONTROL - HOW TO START
=================================

OPTION A - Just look at it (nothing to install)
  Double-click:  Demo - open me (no install).html
  It opens in your browser with 32 pretend Autoplayers.

OPTION B - Run the real tool
  1. Double-click:  Start Autoplayer Control.bat
  2. First time only: if it says .NET 8 is missing, install it from the
     page that opens, then double-click the .bat file again.
  3. Wait (first start 1-3 minutes). The browser opens by itself.
  4. Keep the black window open while you use the tool.
     Close it to stop the tool.

If the browser does not open, type the address shown in the black
window (for example http://localhost:5080) into the browser.
